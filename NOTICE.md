# NOTICE

## art-project — pivot statement

**art-project** is a pre-studio articulation scaffold for practice-based
artistic research, distributed as a Claude Code plugin. It was pivoted from
**art-paper v0.1.0** (which was itself forked from
**academic-research-skills v3.9.4.2** by Cheng-I Wu); the paper-authoring
scope of the predecessor was dropped, and the suite was rescoped to the
propositional articulation phase that precedes studio work.

**Maintainer.** Joon-Hyung Bae (`joonhyungbae` on GitHub; `jh.bae@kaist.ac.kr`).
Solo personal project, developed in personal time on personal equipment
using self-paid AI subscriptions. Contains no confidential information from
any employer.

**Companion paper.** A reconstruction-benchmark compliance audit is in
submission to *Digital Creativity* (Routledge / Taylor & Francis). The
working draft and reproducibility package live in a sibling repository that
will be released through the paper's supplementary-materials channel after
acceptance.
