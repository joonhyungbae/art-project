## 1. Background & Motivation

ARS is a production-grade pipeline for **empirical scientific papers**. Its DNA assumes:

- **Evidence hierarchy:** meta-analysis > RCT > cohort > case report (CLAUDE.md "Key Rules").
- **Structure:** IMRaD (Introduction–Method–Results–Discussion) and 5 sibling empirical patterns.
- **Methodology:** PRISMA systematic review, statistical visualization standards, psychometric terminology.
- **Reviewers:** quantitative/qualitative methodology experts, Q1–Q4 journal-tier framing.
- **Citation:** APA 7.0 (+ 4 sibling numeric/author-year formats).
- **Ethics:** IRB / anonymity / de-identification glossaries.

**SIGGRAPH Asia Art Papers are a different genre.** They are juried for **artistic merit + scholarly/conceptual contribution to the art-and-technology discourse**, with proceedings on the ACM Digital Library (verify category/venue against the current CFP). The load-bearing differences:

| Axis | ARS (empirical) | art-paper (practice-based art) |
|---|---|---|
| Primary evidence | data, statistics, prior empirical studies | **the artwork itself**, its making, exhibition, and reception |
| Knowledge claim | generalizable findings | situated insight from creative practice (practice-based / practice-led) |
| Structure | IMRaD | context → conceptual framework → the work → realization → reflection |
| Validity | reliability, replication, statistical power | conceptual coherence, artistic significance, documentation rigor |
| Reviewer | methodologist | curator / practitioner-researcher / art-science critic / technical realization reviewer |
| Citation | APA 7.0 | **ACM Reference Format** (`acmart`) |
| Disclosure | ICLR/NeurIPS/Nature AI policy | **ACM / SIGGRAPH Asia AI-usage policy** |

> **Venue caveat (apply throughout):** SIGGRAPH Asia Art Papers submission specifics (page limits, exact section requirements, anonymization rules, current AI-disclosure wording) drift year to year. Every art-paper reference file that encodes a venue specific MUST carry a "verify against current CFP" note and an access date, mirroring the ARS `venue_disclosure_policies.md` discipline. art-paper never hard-codes a number it cannot cite.

## 2. Goals & Non-Goals

### 2.1 Goals
1. Fork the 4 skills into art-genre equivalents (see §3 naming).
2. Replace the shared genre layer: structure patterns, evidence model, citation format, disclosure, terminology (§4).
3. Wire the output path to the ACM `acmart` document class (the standard SIGGRAPH Asia / ACM template, obtained from CTAN or the ACM) (§5).
4. Rebrand the plugin packaging so the suite installs as `art-paper` (§6).
5. Preserve every genre-neutral safety mechanism unchanged (§7).

### 2.2 Non-Goals (v0.1)
- Porting all 967 ARS tests. v0.1 ports only the genre-layer-critical lints; full test parity is deferred.
- Supporting non-Art-Paper SIGGRAPH tracks (Technical Papers / TOG, Posters). Single-genre focus.
- Multi-language paper output (art-paper v0.1 is English-only; the bilingual-abstract machinery stays inherited but is not the v0.1 default and the zh-TW-specific configuration paths were removed in the 2026-05-23 Chinese-support drop).
- Auto-submission integration.

## 4. Shared Genre Layer — replacement inventory

New/replaced reference files (Phase 1):

1. **`shared/references/art_paper_structure_patterns.md`** — SIGGRAPH Asia Art Paper structure models (replaces the IMRaD-centric `paper_structure_patterns.md` as the *default*; IMRaD retained as a fallback pattern for art-science hybrids).
2. **`shared/references/art_research_evidence_model.md`** — replaces the "evidence hierarchy" rule. The artwork is primary evidence; documentation, exhibition record, audience reception, technical realization, and situated reflection form the evidence stack. Defines what "a claim must be supported" means when the claim is about an artwork.
3. **`shared/references/acm_reference_format.md`** — ACM Reference Format citation rules, wired to the acmart package's `ACM-Reference-Format.bst` + the acmart `acmart.cls`. Replaces APA 7.0 as default; documents `\bibliographystyle{ACM-Reference-Format}` and biblatex `acmnumeric`/`acmauthoryear` options.
4. **`shared/references/siggraph_acm_disclosure.md`** — ACM / SIGGRAPH Asia AI-usage disclosure (slots into the existing `venue_disclosure_policies.md` mechanism as new venue entries, with access date + verify note).
5. **`shared/references/creative_art_terminology_glossary.md`** — media/creative-tech, copyright/exhibition-rights, collaboration-credit terminology. Replaces the IRB + psychometric glossaries as the active glossary set.

The genre-neutral citation-faithfulness machinery (L3 three-layer emission, contamination signals, triangulation) is **retained as-is** — hallucinated citations are a cross-genre hazard. Only the *format* of the rendered citation changes (ACM, not APA).

## 5. Output Toolchain (ACM `acmart` package)

- art-paper targets the ACM `acmart` document class (the standard SIGGRAPH Asia / ACM template) as its canonical output format. Authors install `acmart` from CTAN or obtain it from the ACM; the package provides `acmart.cls`, `ACM-Reference-Format.bst`, the biblatex `.bbx/.cbx`, samples, and a `Makefile`. (Any separately released acmart clone is distributed independently of this plugin and is not shipped with art-paper.)
- Stage 5 FINALIZE in `art-pipeline` and `format-convert` mode in `art-paper` target **acmart LaTeX → PDF** as the canonical output, replacing the apa7-class path.
- Document class options to support: `sigconf` (SIGGRAPH conference proceedings look) and `acmsmall`/`acmtog` as alternates; the exact class for the Art Papers track is a CFP-verified setting, defaulted to `sigconf` with a verify note.
- IRON RULE preserved: PDF compiled from LaTeX (no HTML-to-PDF).
